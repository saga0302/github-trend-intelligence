The stub version creates dummy data. For real Databricks export, use the Databricks SQL connector:

```python
from databricks import sql

def export_gold_tables_to_parquet(target_hour=None, **context):
    """Export real Gold tables to Parquet."""
    
    with sql.connect(
        host="your_databricks_host",
        http_path="/sql/1.0/endpoints/your_endpoint_id",
        auth_type="pat",
        token=get_token()
    ) as conn:
        cursor = conn.cursor()
        
        for table_name, full_table_name in TABLES_TO_EXPORT.items():
            df = cursor.execute(f"SELECT * FROM {full_table_name}").fetchall_arrow().to_pandas()
            df.to_parquet(f"{DATA_DIR}/{table_name}.parquet", index=False)
            print(f"✅ Exported {table_name}")
```

Install the connector:

## Where Parquet Files Live

### Local Development
```

```

### Streamlit Cloud (Important!)

Streamlit Cloud runs your app in a ephemeral container. Parquet files generated by Airflow **won't persist** unless:

**Option 1: Commit Parquet to Git** (recommended for portfolio)
```bash
git add data/*.parquet
git commit -m "Update data: trending repos"
git push
```
This makes your data visible in the repo and re-deployable.

**Option 2: Store in S3 or Cloud Storage**
Airflow exports to S3, Streamlit reads from S3:
```python
import boto3
import pyarrow.parquet as pq

# In export_to_parquet.py
s3_client = boto3.client('s3')
s3_client.upload_file(f"{DATA_DIR}/trending_repos.parquet", "your-bucket", "data/trending_repos.parquet")

# In app.py
import s3fs
df = pd.read_parquet("s3://your-bucket/data/trending_repos.parquet")
```

**Option 3: Use GitHub as Data Store**
Push data to GitHub, Streamlit pulls from raw.githubusercontent.com:
```python
import requests
url = "https://raw.githubusercontent.com/saga0302/github-trend-intelligence/main/data/trending_repos.parquet"
df = pd.read_parquet(requests.get(url).content)
```

**We recommend Option 1** (commit to Git) for simplicity.

## Troubleshooting

### **Error: "Data file not found"**
- Parquet files haven't been generated yet
- Run Airflow pipeline: `airflow trigger_dag github_pipeline_duckdb`
- Or manually create dummy data (see Testing above)

### **Error: "Missing required columns"**
- Column names from Databricks Gold tables don't match app expectations
- Check table schema:
  ```sql
  SELECT * FROM default.trending_repos LIMIT 1
  ```
- Update column names in `app.py` to match

### **Dashboard shows empty**
- Parquet files exist but are empty
- Check Databricks Gold tables have data:
  ```sql
  SELECT COUNT(*) FROM default.trending_repos
  ```

### **Streamlit Cloud: "404 data file not found"**
- You committed Parquet to Git, but Streamlit doesn't see them
- Verify files are in `data/` and committed:
  ```bash
  git ls-files data/
  ```
- Redeploy Streamlit Cloud
